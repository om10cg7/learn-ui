  - https://www.instagram.com/reel/DfSEEzGTevY/
  - 内容はキャプションで確認
  - このチャット（振り分け）経由で受領し、仕分けルール（url_repo_router）で learn-ui 行きと判定して作成。Claude Code への指示法の話だが、核は用途別の UI モーションライブラリ選定であるため learn-ui に分類

## 内容

主張は「AI が作ったサイトは『AIっぽさ』が出る。Claude Code にこの3ライブラリだけ使わせると消える」。3つとも無料公開で、コードが分からなくてもよい、という前提。

用途別の割り当て:

1. **ロゴ、イントロ → Anime.js**
2. **ボタン、メニュー → Motion**
3. **数字、グラフ → Bklit UI**

指示は平易な言葉でよく、例として「Motion で、ボタンを押したら少し弾むようにして」と言うだけで実装される、と説明している。品質を上げるコピペ用プロンプトは、コメント（合言葉「밤티」、2026-11-10締切）または DM で配布される形式。

## 学び・所感

- ポイントはライブラリの網羅ではなく「部位ごとに定番を固定する」こと。ロゴ／ボタン／グラフで使う道具を先に決めておくと、AI 生成 UI にありがちな「全部同じフェードイン」の単調さが消える、という理屈
- AYA の「見本で伝える」（リファレンス駆動）と同じく、AI への指示を「具体物」に寄せる系の知見。見本が無い場面では、ライブラリ名＋部位の指定が具体化の代替になる
