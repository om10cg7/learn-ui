- 出典：Instagram @rahul_mirji.ai のカルーセル「5 MCP TOOLS FOR BETTER UI」（全9枚、2026-10-29投稿、flutter.deviser 系アカウントの投稿）
  - https://www.instagram.com/p/DfFLCwzkqgJ/?img_index=7
  - 指定の img_index=7 は「WANT ALL 5 LINKS?」とコメント誘導するCTAスライド（5ツールのリスト表示のみ、リンク・手順はなし）。目視確認済み
  - 各ツールのスライドはキャッチコピー＋1文のみで、MCPの設定手順などはなし
- 関連：learn-ai-skills のスキル22（sanskaar.ai のUI向けClaude MCPツール7選。shadcn／21st.dev Magic が重なる）

## 5選

| ツール | キャッチ | 説明 |
|--------|----------|------|
| shadcn/ui | The foundation for your app | クリーンでカスタマイズ可能なコンポーネント。アプリの土台 |
| Magic UI | Add motion to your UI | すぐ使える美しいアニメーション付きコンポーネント |
| 21st.dev | Find better UI components | 膨大な出来合いコンポーネントのコレクション |
| Aceternity UI | Make your UI feel premium | モダンでアニメーション付き、目立つUI向け |
| Radix UI | Build interactions that work | アクセシブルで信頼性が高く、本番利用を意識 |

## 学び

- 「MCPツール」と銘打っているが中身はUIコンポーネントライブラリ／コレクションの紹介で、MCP接続の手順は出てこない。タイトルと中身に少しズレがある
- 役割分担としては、土台（shadcn）／動き（Magic UI・Aceternity）／素材探し（21st.dev）／信頼性とa11y（Radix）の4系統
