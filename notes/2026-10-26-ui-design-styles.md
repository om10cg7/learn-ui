# UI勉強ノート 2026-10-26（UIデザインスタイル15種編）

uiux.build のInstagramリール「Different UI Design Every Designer Should Know」から学ぶ、UIデザインスタイルの総覧。図鑑（index.html、全29種）と対応づけて整理する。

## 出典

- uiux.build のリール（短尺動画）
  - https://www.instagram.com/reel/DcyO-o1NiO4/
  - 形式：白い「くしゃくしゃの紙」背景の左側に番号付きリストが1つずつ増えていき、右側に対応するUI実例が切り替わる。AI音声がスタイル名を順に読み上げる。

## 紹介された15スタイル

| # | スタイル | ひと言メモ |
| --- | --- | --- |
| 01 | Minimalism | 余計な要素を削ぎ落とした最小限の美学 |
| 02 | Maximalism | 色・要素を盛る、ミニマリズムの対極 |
| 03 | Glassmorphism | すりガラス状の半透明＋ぼかし |
| 04 | Neumorphism | 背景から押し出されたような柔らかい影 |
| 05 | Claymorphism | 粘土のような丸みと厚み |
| 06 | Brutalism | 装飾を排した粗い・無骨な表現 |
| 07 | Neo-Brutalism | ブルータリズム＋太い輪郭線と鮮やかな色 |
| 08 | Skeuomorphism | 現物の質感を模した立体表現（初期iOSなど） |
| 09 | Flat Design | 影やグラデーションを排した平坦な表現 |
| 10 | Material Design | Google のデザイン言語。紙とインクのメタファー |
| 11 | Bento UI | 弁当箱のように区切られたカードレイアウト |
| 12 | Y2K Design | 2000年前後の近未来・メタリックな世界観 |
| 13 | Retro Design | 過去の時代様式を引用する表現 |
| 14 | Cyberpunk | ネオンとダークな近未来世界観 |
| 15 | Editorial Design | 雑誌編集のような組版中心の表現 |

## 学び・図鑑との対応

- 図鑑（index.html、全29種）の「質感・モーフィズム」には Glassmorphism、Neumorphism、Claymorphism が、「レイアウト構造」にはベントーグリッドが収録済みで、この15種と重なるものが多い。
- 一方で Maximalism、Skeuomorphism、Material Design、Y2K、Retro、Cyberpunk、Editorial Design あたりは、図鑑の29種とは切り口が違う（スタイル／世界観ベースの分類）。図鑑へカードを追加する候補として残す。
- 分類の軸が教材ごとに違うこと自体が学び：図鑑は「UIの部品・動き・原則」寄り、このリールは「見た目の流派」寄り。
