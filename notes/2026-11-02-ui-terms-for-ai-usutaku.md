# AIでサイトを作る時に効くUI用語7つ（usutaku）

- 出典：Instagram @usutaku（Usui Takumi）のリール「AIでサイトを作る時は専門用語覚えると楽」（2026-10-13投稿）
  - https://www.instagram.com/reel/Deb8SvczbY6/
  - 内容はキャプション全文で確認
- 位置づけ：初歩の用語集。うち ハンバーガーメニュー／パンくずリスト／モーダル は図鑑に収録済み

## 7用語

| 用語 | 意味 |
|------|------|
| ハンバーガーメニュー | 3本線のボタン。押すとメニューが出る（図鑑収録済み） |
| パンくずリスト | 「ホーム＞一覧＞詳細」と現在地を示す。押すと上の階層に戻れる（図鑑収録済み） |
| カルーセル | 横に並んだ画像をスライドで切り替える |
| モーダル | 画面の上に重なる小窓。閉じるまで後ろは操作できない（図鑑収録済み） |
| アコーディオン | タップで中身を開閉できる |
| ラジオボタン | 複数の選択肢から1つだけ選ぶ |
| プルダウンメニュー | 押すと選択肢が下に一覧で出る |

## 学び

- 主張は「用語を知るとAIへの指示が楽になる」。曖昧な見た目の説明（「あの3本線のやつ」）より用語一発の方が、生成結果が安定する
- 用語集としては基礎レベルで、図鑑の既存カードと重なるものが多い。新規性は「AIプロンプト用」という切り口の部分
