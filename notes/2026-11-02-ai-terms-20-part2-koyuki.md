## 20語

| # | 用語 | 一言で |
|---|------|--------|
| 01 | Few-shot | 例を見せて真似させる |
| 02 | MCP | AIと道具をつなぐ共通の規格 |
| 03 | Overfitting（過学習） | 練習だけ得意で本番に弱い |
| 04 | Reasoning Model | 答える前に考える時間をとる |
| 05 | Synthetic Data | AIが作った学習用のデータ |
| 06 | Parameters | 学習で調整された数字の数 |
| 07 | Guardrails | 危ない入力と出力を止める柵 |
| 08 | Multimodal | 文字と画像と音声をまとめて扱う |
| 09 | Knowledge Cutoff | 学習データが終わっている日付 |
| 10 | Tool Use | AIが自分で道具を呼び出す |
| 11 | Distillation（蒸留） | 大きいモデルの力を小さく移す |
| 12 | System Prompt | 最初に渡しておく決まりごと |
| 13 | Vibe Coding | 雰囲気で頼んでコードを任せる |
| 14 | Benchmark | 同じ問題で性能を比べる |
| 15 | Prompt Injection | 文章に紛れた命令で乗っ取る |
| 16 | Pre-training | 大量の文章で土台を作る学習 |
| 17 | Grounding | 答えを根拠に結びつける |
| 18 | Zero-shot | 例を見せずにそのまま頼む |
| 19 | MoE | 入力ごとに一部の専門家が動く |
| 20 | Inference（推論） | 学習済みのモデルで答えを出す |

## 学び

- 全体像：学習まわり（Pre-training／Overfitting／Distillation／Parameters／Synthetic Data）と、使い方まわり（Few-shot／Zero-shot／Tool Use／MCP／System Prompt）が半々。AIを「使う側」の語彙として揃えた選定
- 比喩の付け方が平易で、Overfitting＝「練習だけ得意で本番に弱い」、Guardrails＝「柵」など、初学者向けの言い換えとして参考になる
