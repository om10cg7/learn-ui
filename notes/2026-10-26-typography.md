## 1. ブランドロゴのフォント（Brand Typography Study）

- 出典：uiux.build のカルーセル投稿（全5枚）
  - https://www.instagram.com/p/De9LqFmjXZ6/
  - リンク指定は5枚目（VOGUE）
- 構成（UIの見せ方）：全スライド共通のレイアウトで、上部にブランドロゴ、下部にフォント名を配置。レイアウトを揃えることで、フォントそのものの違いが比較しやすくなっている。
- 各ブランドと使用フォント：
  | ブランド | フォント |
  | --- | --- |
  | Apple | Myriad Pro |
  | Netflix | Netflix Sans |
  | Google | Product Sans |
  | Disney | Waltograph |
  | VOGUE | Didot |
- 5枚目（VOGUE）の目視確認（ブラウザで実物を確認）：
  - 背景は純白ではなく、淡いクリーム／ベージュ系のオフホワイト。
  - 上下2段レイアウト：上部中央に小さな見出し「BRAND TYPOGRAPHY STUDY」、左上に「Logo」ラベル（黄色のマーカー状ハイライト）、上半分中央に大きく黒の「VOGUE」ロゴ。中央に細い黒の水平線を挟み、下段は左寄りに「Font」ラベル（水色系ハイライト）、中央に大きく「Didot」。
  - VOGUEロゴはモダンセリフ（ディドーン系）で、縦画が非常に太く横画が極細という強いコントラスト。全大文字で字間は比較的詰まっている。
  - ラベル（Logo / Font）は太めのサンセリフで、ハイライト色だけを変えて区別している。
- 学び：ロゴは「絵」ではなくタイポグラフィでできているものが多い。特にVOGUEのDidotは、細いセリフと太い縦画のコントラストが強いハイファッション系セリフ体の代表例で、字形そのものがブランドの世界観を作っている。

## 2. UI向けフォントペアリング8種（The Ultimate Typography Pairing Guide）

- 出典：uiux.build のカルーセル投稿（全4枚）
  - https://www.instagram.com/p/DeysXzIGnyx/
  - キャプションの主張：良いタイポグラフィが良いUIを作る（Good typography makes great UI）
- 紹介されていた8ペアリングと向いている用途：
  | # | 組み合わせ | 向いている用途・印象 |
  | --- | --- | --- |
  | 01 | Playfair Display + Inter | ラグジュアリー／エディトリアル（優雅さと明快さ） |
  | 02 | Space Grotesk + Inter | テック／SaaS（大胆な見出し） |
  | 03 | DM Sans（+ DM Serif） | プロダクト／ダッシュボード（明快さ） |
  | 04 | Manrope + Open Sans | フィンテック／分析（数字を語らせる） |
  | 05 | Sora + DM Sans | AI／スタートアップ |
  | 06 | Lora + DM Sans | エディトリアル／コンテンツ（読み物に余白を） |
  | 07 | Outfit + Inter | モバイル／EC（シンプルな見た目） |
  | 08 | Plus Jakarta Sans（ExtraBold + Regular） | SaaS／Webアプリ（無理なく設計された印象） |
- パターンとして読み取れること：
  - 見出しに個性のあるフォント、本文に読みやすいサンセリフ（Inter、DM Sans など）を合わせるのが基本形。
  - Inter と DM Sans は「本文役」として繰り返し登場する。迷ったら本文はこの2つから選ぶのが実務的。
  - 太さの対比（ExtraBold の見出し + Regular の本文）だけでもペアリングとして成立する。
- 締めの言葉：Good typography is never an accident.（良いタイポグラフィは偶然には生まれない）
