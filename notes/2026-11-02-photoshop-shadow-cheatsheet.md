## 影の種類6つ

1. **Drop Shadow**：オブジェクトの後ろに影を作り、奥行きと分離感を生む
2. **Inner Shadow**：内側の縁に影を加え、奥行きや押し込まれた見た目を作る
3. **Outer Glow (Shadow)**：縁の周りに柔らかい光を作り、発光効果に適する
4. **Cast Shadow**：表面に影を落とし、写実性と接地感を加える
5. **Layer Shadow**：複数の影を組み合わせ、より自然な結果を作る
6. **Perspective Shadow**：遠近法に沿わせ、オブジェクトをよりリアルに見せる

## 覚えておくべき要点

- 光の方向が影の方向を決める
- 柔らかい影は自然に、硬い影は大胆に見える
- 控えめな効果には低い不透明度を
- デザイン全体で影を一貫させる

## ドロップシャドウ推奨設定（解説欄の数値）

| 項目 | 推奨値 |
|------|--------|
| Blend Mode | Multiply（最も一般的） |
| Opacity | 40〜60%（デザインによる） |
| Angle | 120°（Use Global Light を使用） |
| Distance | 10 px |
| Spread | 0% |
| Size | 20 px |
| Contour | 読み取り不可 |

※画像内のダイアログ例では Opacity 75% 表示もあり（例示と推奨値は別物として扱う）。

## QUICK TIPS

1. 適切なブレンドモードを使う（Multiply が最も一般的）
2. 控えめな影のために不透明度を低く保つ
3. 影の方向を光源に合わせる
4. 写実性のために柔らかい縁を使う
5. より良い奥行きのために複数の影を組み合わせる
6. やりすぎを避ける

## COMMON MISTAKES（よくある間違い）

1. 影の方向が光源と合っていない
2. 不透明度が高すぎて不自然
3. 硬い縁（スタイル上の意図的な選択を除く）
4. すべての要素で影が同じに見える
5. 影が落ちる表面への考慮がない

## 学び

- 影の説得力は「設定値」より「光源の一貫性」で決まる。角度120°＋グローバルライトで全体の光を統一するのが実務の型
- UI向けの色付きシャドウ（design-cheat-codes）とは対照的に、こちらは写真・印刷寄りの「写実の影」。用途で使い分ける
