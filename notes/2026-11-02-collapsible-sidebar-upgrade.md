## 題材

ダッシュボード用サイドバーを、Basic版「MyPanel」と Premium版「ProPanel」で左右に並べて比較するデモ。メニュー項目は両版共通：Dashboard / Messages / Projects / Calendar / Analytics / Users / Settings。

## 折りたたみの挙動（共通）

- 右上のトグルボタンで、展開状態（アイコン＋ラベル）⇔ 折りたたみ状態（アイコンのみの細いレール）を切り替え
- 切り替えは瞬時ではなく、幅が滑らかに縮むトランジション（秒数・イージングは動画から読み取り不可）
- 折りたたむとラベルが消え、プロフィールもアバターのみに。並び順とアクティブ表示は維持される

## Basic → Premium の差分

| 観点 | Basic（MyPanel） | Premium（ProPanel） |
|------|------------------|---------------------|
| 配色 | 白・淡グレー基調、選択中は淡い紫 | 白地＋紫グラデーションのアクティブ表示、アイコン・ロゴも紫系で統一 |
| 階層 | フラットな一覧（展開矢印なし） | 項目右端にシェブロン、Dashboard 配下に Overview / Performance 等のサブ項目が開く |
| バッジ | なし | Messages 等にピンク系の小さなバッジ（数字は読み取り不可） |
| プロフィール | 下部にアバター＋名前（Alex Morgan） | カード風のプロフィール欄＋右端に「…」メニュー |
| ホバー | 弱い | 紫グラデーションのハイライトなど強い演出。ツールチップも訴求点（文言は読み取り不可） |

## 学び

- サイドバーの「格上げ」は新機能の追加ではなく、既存要素の質上げの積み重ね：アクティブ表示を単色→グラデーション、フラット→階層（ドロップダウン）、通知バッジ、プロフィールカード化、ホバー演出
- 折りたたみ時は「レール化」が定番解。モバイルメニュー8種の Rectangular（左端の縦レール）と同型で、デスクトップでも画面幅の節約と集中に効く
- ラベルが消える折りたたみ状態では、アイコンの識別性とツールチップがラベルの代替になる
