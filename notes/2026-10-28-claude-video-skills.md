## 3. 間取り図から実写っぽい室内ウォークスルー動画を作るワークフロー（@ohneis652）

- 出典：https://www.instagram.com/reel/De-LrmAixqM/
- 手順4ステップ：
  1. 実モデルを作る：Claude Opus 5.5で間取り図からBlenderに家を正確に再構築。壁・ドア・部屋の大きさを先に固定する
  2. 線を1本引く：平面図の上にカメラの動線を描く。高さは目線の約1.5m、各部屋でゆっくりになる動き
  3. 各部屋を静止画で固定する：素材を統一（コンクリート、明るい松材、白いリネン、柔らかい昼光）して、リビング／寝室／テラス／キッチンが「同じ1軒」に見えるようにする
  4. Seedance 2.5で実写化：Blenderのアニメーションを「動きを決める動画」＋開始フレームとして渡し、AIはその動き通りに見た目だけ置き換える
- 肝：レイアウトはAIに考えさせないこと。だから途中で廊下が増えたりせず破綻しない、という主張
- 締め：「WORKFLOW」とコメントで全セットアップ配布
- ユーザーとの接点：上安の3Dサイトモデルを作った流れと逆で、あれは3Dが完成形、こっちは3Dを“動きの型”にして最後にAIで実写化するやり方。

## 4. Claude Code × Muse連携でAI動画を作る（@kou_ai.in_sta）

- 出典：https://www.instagram.com/reel/De__m3OMHjz/
- 紹介されている手順：
  1. Muse for Mac（スマホ版じゃなくPC版）を入れてログイン
  2. 設定で招待コードを入れて、期限なしの10億トークンを受け取る
  3. Claude Codeに「Museと連携して」と頼み、あとは「こんな動画作って」と言うだけ。プロンプト作成→Museへ送信→保存まで自動、写真1枚から動画、最大3本同時生成、だそうです
- 鵜呑み注意（要約時に本人へ伝達済み）：
  - 10億トークンの招待特典自体は本物で、招待した側・された側の両方に入り、期限なしと表示される例も確認されている
  - ただし「作り放題」は盛り表現。Museの動画は1本約10秒、1回の依頼で最大6本程度で、作るほど利用枠／トークンは減る
  - 締めは「フォロー＋よく使うAIをコメントで招待コードDM」という、紹介側にも10億入る集客型
  - ユーザーはもうMuseを使っているので、新規登録の招待コードの話は対象外
