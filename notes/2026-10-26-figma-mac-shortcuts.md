# UI勉強ノート 2026-10-26（Figma Macショートカット編）

uiux.build のInstagramカルーセル投稿「Figma Mac Shortcut Keys」から、ショートカットチートシートの構成をメモする。Windows版はプロフィール側で別途案内される形式。

## 出典

- uiux.build のカルーセル投稿（全2枚）
  - https://www.instagram.com/p/DXay6wuDHcu/

## 内容

### 1枚目：カテゴリ別ショートカット（MAC Shortcuts）
色分けされた3セクションで段階的に並ぶ：

| セクション | 内容の性格 | 例 |
| --- | --- | --- |
| INTERFACE | 表示・移動の基本操作 | View Comments、Zoom In、Move |
| EDITION | 編集操作 | （編集系コマンド群） |
| PRO EDITION | 上級機能 | Add Auto Layout など |

基本ナビゲーション→編集→プロ機能という並びが、そのまま学習の順路になっている。

### 2枚目：Figma Hotkey Cheatsheet
アクションごとに Mac と Windows の対応キーを並べた対照表。緑のアイコンで統一感を出している。

## 学び

- チートシートの型は「カテゴリで覚える版」と「対照表で引く版」の2枚構成。学ぶ用と実務で引く用を分ける情報設計。
- UIデザインの学習はツール操作の速さが下支えになる（リソース編の「Figmaで練習する」と地続き）。特に Auto Layout 系は現代のUI制作の要。
- 個別キーの一覧はスライド画像側に記載。本ノートでは構成と使い方を記録する。
