# 配色パレットの作例4つ（yamayuki_design）

- 出典：Instagram @yamayuki_design のリール（2026-10-29投稿）
  - https://www.instagram.com/reel/DfEsNk6NAkH/
  - 「デザインの引き出しを効率よく増やす」シリーズ。架空ブランドの完成モックアップ＋3色パレット（色名・HEX付き）を4例見せる構成。内容は動画解析に基づく

## 作例4つ

| ブランド | 業種・トーン | 3色（色名／HEX） |
|----------|-------------|------------------|
| NOVA | コンセプト系 | Off Black #000000 / Vivid Magenta #FF0043 / Lime Green #C7F500 |
| NEXT PASS | コーポレートサイト | Greige #EDE0D3 / Royal Blue #0033CC / Vivid Orange #FF9000 |
| GLASS SHOP | ファッションブランド | Coral Pink #FF7BA5 / Crimson Red #DC0030 / Olive Lime #9CB800 |
| CONETI | 若者向けコミュニティ | Lime Green #C7F500 / Lavender Purple #C68FE7 / Vivid Red #FF1B1B |

## 学び

- 型は「地の色1＋主役1＋差し色1」の3色構成。NOVA と CONETI は Lime Green #C7F500 を共有するなど、差し色の使い回しも見せている
- コーポレート例だけ彩度を落としたグレージュ地＋青＋オレンジで、業種ごとに「鮮やかさの上限」が違うことを作例の対比で教える構成
- パレット単体ではなく完成モックアップと並べることで、「色→実際の見え方」の対応が一目で分かる
