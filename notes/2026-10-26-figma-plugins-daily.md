# UI勉強ノート 2026-10-26（毎日使うFigmaプラグイン編）

uiux.build のInstagramカルーセル投稿「Top Figma Plugin Every Designer Should Know」から、日常のデザイン要素づくりに効くプラグインのカテゴリをメモする。プラグイン50選（`notes/2026-10-26-figma-plugins-50.md`）のコンパクト版。

## 出典

- uiux.build のカルーセル投稿（全2枚、「01 / 02」バッジ付き）
  - https://www.instagram.com/p/DXb7gXuk2IF/
  - 様式：白背景に紫アクセント＋Figmaロゴ。締めは「More productivity. More creativity. All in Figma.」

## 内容

1枚目：「Figma Plugins — For daily design elements」。ワークフローを速くするために厳選したリストで、「次のデザインセッション用に保存を」と促す導入。

2枚目：「Top Figma Plugins」を4カテゴリに色分けして整理：

| カテゴリ | 例として挙がるプラグイン |
| --- | --- |
| Icons | IconScout、Feather 系など |
| Illustrations | Blush など |
| Images | Unsplash など |
| Mockups | Figmockups など |

## 学び

- 50選のような網羅リストと違い、こちらは「毎日使う要素（アイコン・イラスト・画像・モックアップ）」という利用頻度の軸で4カテゴリに絞っている。初心者はまずこの4分類から揃えると迷わない。
- カテゴリごとの色分けは、情報量の多いリストを読みやすくする基本テクニック（色彩編の「色に役割を持たせる」と同じ発想）。
