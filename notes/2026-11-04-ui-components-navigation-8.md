## 8種

| コンポーネント | 定義 | いつ使うか（と使わない条件） |
|----------------|------|------------------------------|
| Accordion | 開閉するセクション。要約は常に見せておく | 長いが全員に必要ない追加内容に。タイトルが中身を要約していることが条件。必須の手順には決して使わない |
| Breadcrumbs | 現在地を示し、戻る出口を与える | 2階層を超える実際の階層がある場合のみ。平坦なサイトでは装飾にすぎず、場所を取るだけ |
| Sidebar | セクションを示すサイドナビ（コンパクト版はアイコンのみ） | セクションが多く、戻らずに切り替える必要がある場合。2〜3個ならバー自体が不要 |
| Search bar | コンテンツ内を検索する入力欄 | コンテンツが多く、利用者が探すものを既に知っている場合に、目立つ場所へ |
| Filter chips | パネルを開かずに一覧を絞る高速フィルター | パネルを開かずに絞り込みたい場合 |
| Modal | 判断や入力のために画面を中断するウィンドウ | 購入確認など全面的な注意が必要な場合のみ。ブロックせずに済むなら他の手段を |
| Bottom sheet | 画面から離れさせず、下から選択肢や詳細を出す | フィルター等の補完的な選択肢で、全体を中断する必要がない場合 |
| Card | 内容を要約し詳細へつなげるブロック | 似た要素が多数あり、比較できるよう並べる場合 |

## 学び

- 各コンポーネントに「使う条件」だけでなく「使わない条件」（平坦なサイトのパンくずは装飾、必須手順にアコーディオンは不可、モーダルは最終手段）が付いているのが実務的
- usutaku の「AI向けUI用語7つ」と題材が重なるが、こちらは用語の意味ではなく選定基準の教材。モーダルとボトムシートの使い分け（中断が必要か否か）が特に明快
