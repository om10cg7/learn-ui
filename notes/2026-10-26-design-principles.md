# UI勉強ノート 2026-10-26（デザイン原則編）

uiux.build のInstagramリール「Design Principles Every Designer Should Know」から、デザインの基礎原則をメモする。赤い角丸正方形だけを使ったミニマルなスライドで原則を図示する教材。

## 出典

- uiux.build のリール（短尺動画）
  - https://www.instagram.com/reel/DaClNCDzYd9/
  - 形式：薄グレーの背景に赤い角丸正方形のグラフィック、原則名を赤文字で上下に表示。音声はタイプライターのようなクリック音のみで、言葉の説明はない（図そのもので原則を伝える構成）。

## 紹介された原則（11項目）

| 原則 | 図の示し方・要点 |
| --- | --- |
| Balance（バランス） | 均等なグリッド配置で視覚的な釣り合いを示す |
| Hierarchy（階層） | 要素の大きさを変えて、重要度の順序を作る |
| Composition（構成） | 要素の配置バリエーション全体の組み立て |
| Left Alignment（左揃え） | 左端で揃えると視線の起点が安定する |
| Right Alignment（右揃え） | 右揃えの見え方との対比 |
| Centre Alignment（中央揃え） | 列を中央で揃える配置 |
| Repetition（反復） | 同じ形を均一に繰り返して統一感を作る |
| Contrast（コントラスト） | 塗りと輪郭線の四角を交互にして差を際立たせる |
| Negative Space（余白） | 小さい要素群の中に大きな1要素を置き、余白の働きを示す |
| Scale（スケール） | 極端に大きな1要素と多数の小要素の対比 |
| Unity & Proximity（統一と近接） | 近くに置かれた要素同士がグループとして認識される |

## 学び

- 原則は「言葉」より「図の対比」で理解する教材。要素は正方形だけに限定し、色も赤1色に絞ることで、配置と大きさの差だけが原則として浮かび上がる（＝教材自体が反復と統一の実例）。
- 既存ノートとの対応：Hierarchy はリニューアル編の「ヒエラルキーの弱さ＝古さの正体」、Contrast と余白は配色編（ダークアンカー、コントラスト比）と直結。Alignment と Proximity はダッシュボードのカード配置（ルール2「関連データをまとめる」）の基礎理論にあたる。
- この11原則は図鑑の「動き・UX原則」カテゴリとは別軸の、グラフィックデザイン由来の基礎。UI を作る前の土台として押さえる。
