# MacBookを顔で開錠する無料OSS「Glance」（ai.asap.kr）

- 出典：Instagram @ai.asap.kr のカルーセル（2026-11-07投稿、韓国語）
  - https://www.instagram.com/p/Dfd5xYnDxc7/?img_index=2
  - キャプションに仕様と注意点が明記されているため、目視確認なしで記録
  - 本体：Glance（github.com/jonnyoo/glance、MITライセンス）

## 仕組み

- Mac がロック／スリープ解除のタイミングで、ノッチのカメラが顔を探し、本人なら保存しておいた Mac パスワードを代わりに入力して開錠する（iPhone の Face ID 風）
- 顔は512個の数値（特徴量）だけを保存し、写真は破棄。認識は全て Mac 内で処理
- パスワードは Touch ID で守ったキーチェーンの鍵で暗号化。眼鏡あり等の複数の見た目を別々に登録可能
- 動作環境：macOS 15以上、Apple Silicon／Intel 両対応、dmg でインストール

## 注意点（作者自身の明言）

- Face ID ほど安全ではない。Mac のウェブカメラは顔を平面でしか見ないため、写真は防げても動画は確実には防げない
- あくまで利便性のための機能という位置づけ

## 学び

- 「顔データ＝数値だけ保存して写真は捨てる」「処理は端末内」というプライバシー設計の型が明快。本人認証をパスワード自動入力で肩代わりする発想なので、安全性の限界も作者が自分で線引きしている点が誠実
