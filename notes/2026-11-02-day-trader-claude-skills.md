## 目玉：「Time Machine」

エントリー前に、その銘柄自身の直近の価格変動（5分足）を使って「その日の残り」を10,000回リプレイし、計画中トレードの現実的な確率を出す。

- 例：ターゲット先行 29.4%／ストップ先行 25.5%／どちらも付かず引け 45.1%
- 「ほぼコイントス」と正直に表示して煽らない、という設計姿勢が売り

## 11種のスキル

| Skill | 役割 |
|-------|------|
| Scanner | 数千のチャートからセットアップ（オープニングレンジ・ブレイクアウト等）を検出 |
| News | 株価を動かすヘッドラインを追跡 |
| Entry | エントリーシグナルを監視 |
| Exit | エントリー前にストップとターゲットを設定 |
| Time Machine | トレードを10,000回リプレイして確率を提示 |
| Risk | リスクチェック |
| Budget | ポジションサイズ計算 |
| Broker | ブローカー連携 |
| Alerts | アラート |
| Analyst | 分析 |
| Congress | 米議員の株式取引（公開届出）を追跡。NVDA、AAPL、MSFT、TSLA の例 |

## 安全設計

- APIキー不要
- デフォルトはペーパートレード（仮想売買）
- 本人の明示的な「yes」なしに実売買は実行されない

## 学び（ツール設計として）

- AIエージェントに金融操作をさせる場合のガード設計例：既定で無害（ペーパー）、実行は明示承認制、確率を盛らずに提示
- 「10,000回リプレイで確率を出す」はモンテカルロ的な検証をSkill化したもので、判断前にオッズを見せるUXが本体
