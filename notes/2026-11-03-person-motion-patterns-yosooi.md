# 人物ありモーション図解12種 person系（よそおいさん）

- 出典：Threads @yosooi3 の投稿「人物ありのモーション図解を追加しました！スキルは再ダウンロードしてね」（2026-11-03投稿）
  - https://www.threads.com/@yosooi3/post/DfQ55tGk3OR
  - 「よそおい図解モーション150」（yosooi.jp）というスキルへの追加分。人物が話す縦型動画を前提にしたモーションパターン12種の図解シート
  - 上段6件はタイトル・解説まで目視で読み取り。下段6件はタイトル・解説が画像下端で切れて読み取り不可（コードと動画内容のみ確認）

## 上段6種（確認済み）

| コード | タイトル | 内容と用途 |
|--------|----------|------------|
| person/talk | 話す人＋名前テロップ | 人物だけを見せるつなぎ。ゆっくり寄りながら名前と肩書きのテロップ。自己紹介・導入・図と図のあいだに |
| person/backdrop-word | 背後に巨大な語（攻め） | 画面幅いっぱいの語が後ろに落ち、頭が語の前に来て奥行きが出る。キーワード提示・章の頭に |
| person/orbit-icons | 頭のまわりをアイコンが周回（攻め） | アイコンの玉が頭を周回（手前は人物の前、奥は頭の後ろ）。テーマの多さ・道具一覧に |
| person/spotlight | 暗転スポットライト（攻め） | 部屋が暗転し人物だけが照らされ、頭の後ろに光る語。本題に入る瞬間・強調したい一言に |
| person/checklist | チェックリストカード | 顔の横（縦画面はあごの下）にすりガラスカード、話に合わせてチェックが入る。手順・条件確認に |
| person/graph-card | 数字が伸びるグラフカード | すりガラスカードで折れ線が伸び数字がカウントアップ。成果・実績の紹介に |

## 下段6種（コード・映像のみ確認、タイトル・解説は読み取り不可）

- person/headline-wall：背景の壁に見出しカードが並ぶ（「広告費を半分にした…」「…が2.4倍になった日」等）
- person/strike：「ではなく」→大きく「信頼」と表示
- コード不明：頭と肩に紫の輪郭線、「3年前の自分」の表示
- person/split-headline：「SNSは『量』より『設計』」、要点を紫枠で強調
- コード不明：右下に紫の帯で「ここ大事」
- person/grid-tile：数字タイルのグリッド（12.4万／31万／44万など）、中央に人物写真タイル

## 学び

- モーションを「person/talk」のようにコード名で管理し、用途（導入／章頭／手順／実績）までセットで言語化しているのがこのスキルの特徴。「言語化の始祖」の名の通り、動きに名前と使いどころを与える設計
- 「攻め」バッジで強い演出系（backdrop-word／orbit-icons／spotlight）を区別しているのも実務的
